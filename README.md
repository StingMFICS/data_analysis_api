# Data Analysis API

This is a simple API for uploading and analyzing data files (CSV or JSON).

## Features
- Загружает файл и анализирует содержимое
- Поддерживает форматы CSV и JSON
- Предоставляет такие сведения, как среднее, медианное и нулевые значения.
